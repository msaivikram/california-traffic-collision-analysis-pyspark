# California Traffic Collision Analysis using PySpark

## Project Overview

This project performs ETL and data analysis on California traffic collision data using PySpark.

The project focuses on data loading, data cleaning, transformation, and analysis to identify useful patterns and insights from traffic collision data.

## Objectives

- Perform ETL operations using PySpark
- Clean and transform the dataset
- Analyze traffic collision data
- Identify important patterns and trends
- Generate meaningful data-driven insights
